# W001 Review Hub — Cycle 1 Proof of Concept

Static GitHub Pages site. Upload all files in this folder to the root of a GitHub repository, then enable Pages from the main branch.

Includes 10 quizzes × 10 items. No login or stored student data. Question content lives in `quizzes.js`.

QR codes are generated automatically from the published URL using QRCode.js loaded from cdnjs. The quizzes still work if that library is blocked; only the QR popup would fail.
